## M5 波次胜负交付（commit 9a5ad5e）

- 验收：tests/m5.test.ts 8/8 全绿，全量 54 passed，tsc 无报错。
- 【重要】pendingSpawns 语义由用例反推，两种触发不同：
  - time 波：全部条目入队（含已到点项），出生后保留——pendingSpawns 是完整排期表，
    用「已出生集合」（WeakMap 按 BattleState 隔离，对象引用标记）保证只出生一次；
  - clear 波：已到点条目当场出生不入队，只有未来条目入队。
- 排期锚点统一为排期链 anchor = lastSched + delay（第一波记 0）：
  time 触发 state.time > anchor 才开（恰好等于不开）；clear 触发按条件连续成立
  时长 clearElapsed > delay 开（条件不成立清零）；clear 波迟到开始时已到点条目当场补出生。
- 为什么不用游标：排序插入会让已出生前缀不再是前缀，集合标记对 sort 安全。
- 胜负：objectiveHp ≤ 0 优先判 lost；won = 波全开 + 场上无敌人 + 排期全出完。
