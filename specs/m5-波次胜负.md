# SPEC M5 —— 波次调度与胜负判定

## 目标

按关卡定义（StageDef.waves）按时出怪，管理波次推进，判定战斗胜负。

## 交付物

- 文件：`src/systems/waves.ts`（单文件，≤ 300 行，中文注释）

## 允许 import（白名单）

```ts
import { ... } from "../contracts";
```

## 必须导出的 API（签名一字不差）

```ts
/** 帧更新：波次推进 + 待出生队列出怪 */
export function waveSystem(state: BattleState, dt: number): void;

/** 胜负判定：只从 running 状态进入终局，只发一次 battleEnded */
export function checkBattleEnd(state: BattleState): void;
```

## 合同速览

```ts
interface WaveEntry { enemyId: string; count: number; interval: number; delay: number; spawn: number; }
interface Wave { trigger: "time" | "clear"; delay: number; entries: WaveEntry[]; }
interface PendingSpawn { enemyId: string; spawnIndex: number; at: number; } // at = 绝对战斗时间
interface BattleState {
  stage: StageDef; world: World; bus: EventBus<GameEvent>;
  enemyDefs: Record<string, EnemyDef>;  // 注意：这里的定义已是词条结算后的最终值
  time: number; objectiveHp: number; status: BattleStatus;
  waveIndex: number;         // 已开始的波数（= 下一波下标）
  waveTimer: number;         // 当前波开始后累计时间
  pendingSpawns: PendingSpawn[];  // 按 at 升序
  currentWaveAllSpawned: boolean;
}
// 出生实体组件与 M1/M2 约定一致：identity/position/health/attack/enemyPath/tags
// position 初始 = stage.spawns[spawnIndex]，enemyPath.waypoints = stage.paths[spawnIndex]
// 事件: waveStarted / enemySpawned / battleEnded
```

## 行为规则

### 波次推进（waveSystem）

1. `waveIndex` 初始 0。若 `waveIndex < waves.length`，考察下一波 `w = waves[waveIndex]`：
   - `trigger === "time"`：当「上一波开始时刻 + w.delay ≤ state.time」即开始；
     第一波（waveIndex 0）的"上一波开始时刻"记为 0；
   - `trigger === "clear"`：当「场上无存活敌人 且 上一波已全部出生」条件满足后
     再累计 w.delay 秒即开始；
   - 波开始：发 `{ type: "waveStarted", index: waveIndex }`，重置 `waveTimer = 0`，
     为每条 entry 生成 `count` 个 PendingSpawn：
     `at = state.time + entry.delay + k * entry.interval`（k = 0..count-1），
     `spawnIndex = entry.spawn`；然后 `waveIndex += 1`；
   - 若同帧满足条件立即开始（一个 tick 只开始一波即可，下 tick 继续检查下一波）。
2. `waveTimer += dt`。
3. **出怪**：把 `pendingSpawns` 中所有 `at <= state.time` 的项按序生成敌人实体
   （数值取 `state.enemyDefs[enemyId]`，实体构造方式与 tests/helpers.ts 的
   spawnEnemy 一致），发 `{ type: "enemySpawned", entityId, defId, spawnIndex }`，
   从队列移除；`pendingSpawns` 保持升序。
4. `currentWaveAllSpawned` = 最新波的全部条目都已进入 pendingSpawns（出生与否不管）。

### 胜负（checkBattleEnd）

1. `status !== "running"` 直接返回（保证 battleEnded 只发一次）。
2. `objectiveHp <= 0` → `status = "lost"`，发 `{ type: "battleEnded", result: "lost" }`。
3. `waveIndex === waves.length` 且场上无敌人且 `pendingSpawns` 为空 →
   `status = "won"`，发 `{ type: "battleEnded", result: "won" }`。
4. 其余情况保持 running，不发事件。
