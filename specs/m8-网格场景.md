## 行为规则

### createBattle

- world/bus/rng 按 contracts 工厂创建（seed 用 opts.seed）；
- `dp = globals.initialDp`；`objectiveHp = globals.objectiveHp + globals.tempObjectiveHp`（临时生命合并计入）；
- squad 由 squadOperatorIds 生成（全部 ready，cooldownRemaining 0）；
- wave 状态归零；status "running"；time 0；
- operatorDefs / enemyDefs / effective / globals / stage 原样存入 state。

### stepBattle（顺序不可变）

```
waveSystem(state, dt)        // 出怪与波次推进
movementSystem(state, dt)    // 敌人移动
assignBlocking(state)        // 阻挡判定（注意：无 dt 参数）
combatSystem(state, dt)      // 攻击结算与死亡清理
deploymentSystem(state, dt)  // 费用回复与冷却
checkBattleEnd(state)        // 胜负判定
```

### BattleScene

1. `create()`：读取 `this.scene.settings.data` 里的 `{ battle: BattleState }`。
2. 网格渲染：遍历 `stage.terrain`，每格一个 `rectangle(CELL×CELL)`：
   - 空 `.` #17151f | 道路 `r` #3d3a47 | 高台 `h` #5d5340 | 墙 `#` #101014
   - 出生点 `S` 描边 #4a7ef0 | 防御点 `G` 描边 #e24b4a
   - 左上角写关卡名、坐标原点在 (40, 120)。
3. 每格注册交互区（`setInteractive`），把 (row, col) 存进 game object 的
   `setData("cell", {row, col})` —— M10 依赖此约定部署点击。
4. `update(_time, delta)`：
   - `delta` 上限截断到 100ms（防止切页回来跳帧破坏战斗）；
   - 从 `this.registry.get("battleSpeed")`（缺省 1，M10 会写）读取倍速，
     `this.registry.get("battlePaused")`（缺省 false）为 true 时跳过；
   - 调 `stepBattle(battle, min(delta,100)/1000 * speed)`。
5. 背景 #14121a；本模块不画干员/敌人（M9 负责），不画 HUD（M10 负责）。
