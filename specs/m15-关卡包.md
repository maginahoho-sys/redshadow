## 数据 Schema（与 contracts/types.ts 一致）

```ts
{
  id: "st_<小写标识>_<序号>",
  name: string,
  rows: 5~7, cols: 7~10,
  terrain: string[],                 // 每行长度=cols；字符: . r h # S G
  spawns: Vec2[], goals: Vec2[],     // S 格 / G 格坐标，与 terrain 字符一致
  paths: Vec2[][],                   // 与 spawns 一一对应；首=出生点 末=某防御点；
                                     // 路点间只能正交移动（先纵向后横向），途经格必须 r/S/G
  waves: [{ trigger: "time"|"clear", delay, entries: [{enemyId, count, interval, delay, spawn}] }],
  initialDp: 10~16, dpRate: 0.7~1.0,
  objectiveHp: 3~6（BOSS 关 ≥ 5）,
  isBossStage?: true
}
```

## 新增 4 关设计

| st_rehearsal | 排练惊魂（紧急） | 5×8，高台只有 2 格（远程部署压力大） | 3 波高压，clear 触发 | soldier/hexer/swarm |
| st_finale | 终幕（BOSS） | 7×10，长路给足部署时间，`isBossStage: true` | 4 波：前 3 波混合海，末波 1 只 en_boss_01 + 护卫 | 全部 + boss |

## 设计纪律

- 敌人 id 必须存在于 enemies.json（脚本会查）；
- 每关首波 `trigger: "time"` 且 `delay ≥ 2`（给玩家开局部署时间）；
- 敌人总威胁递增：1 关 ≈ 6 只、2 关 ≈ 10、3 关 ≈ 12、紧急关 ≈ 14、BOSS 关 ≈ 16+1BOSS；
- 出生点/防御点/路径格必须与 terrain 字符吻合（脚本会查）；
- 波与波之间至少 8 秒（time 触发）或 clear+delay ≥ 4。
