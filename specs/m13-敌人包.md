# SPEC M13 —— 敌人数据包（扩至 7 种含 BOSS）

## 目标

扩充 `src/data/enemies.json` 至 7 种敌人（6 普通加 1 BOSS），覆盖各种验证性词条
组合，形成能考验编队配合的怪物池。**纯数据任务。**

## 交付物

- 修改 `src/data/enemies.json`：保留现有 3 种（en_slug / en_soldier / en_runner），
  **追加** 4 种。

## 数据 Schema（与 contracts/types.ts 一致）

```ts
{
  id: "en_<小写标识>_<两位序号>",      // 唯一，前缀 en_
  name: string,                        // 原创剧团/猩红风格
  hp, atk, def, res: number,
  attackInterval: number,               // 秒
  damageType: "physical"|"arts",
  speed: number,                        // 格/秒 0.3 ~ 1.2
  blockWeight: number,                  // 通常 1；BOSS 可以 3（无法被挡 2 以下拦停）
  leakDamage: number,                   // 普通怪 1；中层精英 2~3；BOSS 5
  tags: string[],
  description: string
}
```

## 追加的 4 种设计意图（数值可 ±15%）

| id | 定位 | hp | atk | def | res | speed | damageType | tags |
|---|---|---|---|---|---|---|---|---|
| en_armor_01 | 高防龟（验证法伤价值） | 1600 | 220 | 500 | 0 | 0.35 | physical | ["armored"] |
| en_hexer_01 | 高法抗（验证物伤价值） | 1200 | 260 | 80 | 60 | 0.5 | arts | ["arcane"] |
| en_swarm_01 | 怪海（验证范围输出） | 260 | 90 | 20 | 0 | 0.8 | physical | ["weak","swarm"] |
| en_boss_01 | BOSS：血月主演 | 9000 | 450 | 300 | 40 | 0.28 | physical | ["boss"] |

- BOSS blockWeight=3、leakDamage=5；
- 注意：当前战斗系统只实现了近战攻击的敌人，**不要设计远程敌人**
  （远程敌人属于 M16 后的扩展项，出现会无攻击行为）。

## 验收

1. `env -u NODE_OPTIONS npm run validate:data` 通过；
2. 7 种敌人 id 唯一；普通怪 leakDamage 均为 1；
3. `env -u NODE_OPTIONS npx tsc --noEmit` 无报错。

## 禁止事项

- 不许改已有 3 条；不许改其他文件；数值无非负数之外的业务约束由脚本查。
