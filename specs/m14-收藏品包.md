## 数据 Schema（与 contracts/types.ts 一致）

```ts
{
  id: "rl_<小写标识>_<可选序号>",   // 唯一，前缀 rl_
  name: string,                     // 原创：剧团道具/猩红意象（假面、票根、烛台、剧本残页…）
  rarity: 3 | 4 | 5 | 6,            // 负面收藏品用 1~2
  description: string,              // 一句话说明效果（与 mods 一致，供玩家阅读）
  mods: RelicMod[]                  // 1~3 条词条
}

type RelicMod =
  | { kind: "stat", selector: EntitySelector, stat: StatKey, op: "add"|"mul", value: number }
  | { kind: "global", target: GlobalKey, op: "add"|"mul", value: number }
  | { kind: "grantTag", selector: EntitySelector, tag: string }
  | { kind: "runStat", target: RunStatKey, op: "add"|"mul", value: number };

selector: { faction?: "operator"|"enemy", professions?: [...], tagsAll?: [...], tagsAny?: [...] }
stat: hp/atk/def/res/cost/attackInterval/blockCount/speed/redeployCooldown
global: dpRate/initialDp/objectiveHp/tempObjectiveHp/squadSize
runStat: hope/ingots/objectiveHp/hopeCap
```

## 设计配额（30 件的构成）

| 类别 | 数量 | 示例方向 |
|---|---|---|
| 职业定向强化（professions） | 8 | 近卫攻速/重装生命/狙击攻/先锋费用… |
| 标签定向强化（tagsAll/Any） | 6 | "ranged 全体 atk+10%"、"melee def+20%" |
| 全体干员（faction operator） | 5 | 全员 hp+10%、全员 cost-1（等等价负面交换） |
| 敌人削弱（faction enemy） | 4 | 敌人 hp-8%、speed-15%、def-60… |
| 全局经济（global） | 4 | dpRate、initialDp、tempObjectiveHp、squadSize+1 |
| runStat 开局类 | 1 | 进图时生效（开局希望+1 类，作为纪念品） |
| grantTag 组合技 | 2 | 给远程打 "blessed" 之类标签，配合其他收藏品 selector 命中 |
| **负面收藏品**（rarity 1~2） | 3 | 全员 cost+2、敌人 atk+10%、全员 atk-10% |

## 数值纪律

- 单件 mul 强化 ≤ ×1.35；跨件叠加时注意同 stat 连乘上限（同一属性设计
  最多被 4 件 mul 命中）；
- 一件收藏品内词条 ≤ 3 条；正面收藏品不带负面词条（负面单独成件）；
- description 必须**如实**描述 mods 的实际效果（数字一致）。

## 验收

1. `env -u NODE_OPTIONS npm run validate:data` 通过（selector/stat/target 合法性脚本已查）；
2. 总数 ≥ 30，其中负面收藏品 ≥ 3，覆盖全部 4 种 RelicMod kind；
3. 无重复 id；`env -u NODE_OPTIONS npx tsc --noEmit` 无报错。
