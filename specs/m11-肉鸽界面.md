## 行为规则

### run-bootstrap

- `createRun`：`runStartFrom(runConfig.runStart, 分队mods)` 得初始资源；
  分队 mods 从 runConfig.teams 查；`generateNodeMap(1, floors[0], rng)`；
  hopeCap 用 runConfig.runStart.hopeCap；squadLimit 取 runStart.squadSizeBase。
- `nodeRewards` 表（rng 可复现）：
  | 节点 | 希望 | 源石锭 | 收藏品概率 |
  |---|---|---|---|
  | battle | 1 + rng.int(0,1) | 6 + rng.int(0,6) | 0.25 |
  | emergencyBattle | 2 + rng.int(0,1) | 10 + rng.int(0,8) | 0.4 |
  | boss | 3 | 20 + rng.int(0,10) | 1.0 |
- `pickStage`：battle/emergency 从非 boss 关卡抽（emergency 优先带"紧急"标记——
  无标记则同池）；boss 抽 isBossStage 的关卡；无合适关卡返回第一个。
- `advanceFloor`：floor+1；若 > 5（runConfig.floors.length）→ 探索胜利标记
  （state.eventLog 记录）；否则生成该层节点图、objectiveHp +1（上限内）。

### RogueScene 流程（状态机，存 registry：当前 RunState）

1. **分队选择**：列出 runConfig.teams 卡片（名称+描述），点选 → `createRun`。
2. **节点图**：
   - 节点=圆（颜色：battle #c98a4a、emergency #d04a4a、shop #6fa8e0、event #b26fe0、
     gift #6fc06f、safeCorner #64d9c8、interlude #d8b13c、boss #e24b4a 放大 1.5 倍）；
   - 节点按 `row/col` 摆放（col 0/0.5/1 → x 400/640/880，row → y 递增 90）；
   - next 边画线；已访问节点打勾；**可进入节点**（当前节点的 next，或初始 start）
     描边脉冲，点击进入；
   - 进入 battle/emergency/boss → `pickStage` + M4 求值 + `scene.start("Battle", {...})`；
   - BattleScene 发出 `battle-finished`（won）→ 回 RogueScene：`nodeRewards`
     入账并弹奖励面板 → 确认后回到节点图；boss 胜 → `advanceFloor`；
   - 进入 shop/event/gift/safeCorner/interlude → 弹面板结算（见下）。
3. **商店面板**：`generateShopItems(rng, floor, pools)` 列 4 件商品（名称/价格）；
   点买：源石锭足够 → 扣款、relic 入 relics / ticket 入 recruitTickets /
   life 加 objectiveHp / operator 招募入队 / promotion 对最贵可进阶干员进阶；
   关闭面板 = 完成该节点。
4. **事件面板**：从 events.json 抽 1 个未遇到的（rng），标题/文本/选项；
   条件不满足的选项置灰；选择 → `resolveEvent` → 显示获得物 → 关闭。
5. **招募面板**（shop 与奖励券触发）：recruitTickets 每张券列出 3 名候选
   （operator 包按职业/高级过滤后 rng 取 3），显示希望价格（`recruitCost`），
   点选招募；可重复招募；希望不足置灰。
6. **目标生命/希望/源石锭/当前层** 常驻顶部条；objectiveHp ≤ 0 → 探索失败结算；
   advanceFloor 越过最后一层 → 探索胜利结算：显示楼层、干员数、收藏品数。
7. BattleScene 进入前把 squadLimit（buildGlobals 的 squadSize）与分队的
   effective/globals/enemyDefs 组装好传给 BattleScene（data 参数）。
