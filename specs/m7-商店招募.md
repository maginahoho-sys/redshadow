# SPEC M7 —— 招募·进阶·商店·事件结算

## 目标

实现肉鸽探索层的资源操作：按星级招干员（消耗希望）、进阶、商店生成与定价、
随机事件效果结算。纯逻辑模块。

- 文件：`src/meta/run-ops.ts`（单文件，≤ 400 行，中文注释）

## 合同速览

```ts
interface RunState {
  hope: number; ingots: number; objectiveHp: number;
  squad: string[]; reserve: string[]; promoted: Record<string, boolean>;
  relics: string[]; recruitTickets: string[]; eventLog: string[];
}
interface ShopItem { id: string; kind: "relic"|"ticket"|"promotion"|"life"|"operator"; payloadId: string; cost: number; }
interface EventEffect {
  kind: "hope" | "ingots" | "hp" | "relic" | "ticket" | "operator";
  op: "add" | "remove";
  value?: number | string;   // hope/ingots/hp 为数字（可为负）；relic/ticket/operator 为 id 字符串，"random" 表示随机
}
interface EventOption { text; requireHope?; requireIngots?; requireHp?; effects: EventEffect[] }
interface EventDef { id; title; text; options: EventOption[] }
```

## 行为规则

### 招募 recruitOperator

1. 干员必须存在于 operatorDefs；希望不足返回 false（状态不变）。
2. 消耗 = `costTable[String(rarity)]` ?? 999（表键是字符串化的星级）。
3. `squad.length < squadLimit` 入 squad，否则入 reserve（同样扣希望）。
4. **允许重复招募同一干员**（凑编队、肉鸽特色）。
5. 成功后在 `eventLog` 追加一条（自由格式，含干员 id）。

### 进阶 promoteOperator

1. 干员必须在 squad 或 reserve 中；`promoted[id]` 已为 true 则 false。
2. 消耗 = `promoteTable[String(rarity)]`；3 星及以下无法进阶（表里没有即 false）。

### 商店 generateShopItems

1. 固定生成 4 件商品，kind 从 `["relic","ticket","promotion","life","operator"]`
   等概率抽取（`rng.int`），但保证至少 1 件 relic。
2. 定价（可被验收测试的"高楼层更贵"约束）：
   - relic：`(6 + rarity) * 4 + floor * 2 + rng.int(0, 5)`
     （rarity 从奖池对应 id 查 RelicDef——奖池只给 id，简化：用 `8 + floor * 3 + rng.int(0, 8)`，
      若实现方选择读 rarity，需自行内联一个 rarity 表参数；推荐用简式）；
   - ticket：`8 + floor * 2 + rng.int(0, 4)`；
   - promotion：`10 + floor * 2`；
   - life：`6`；operator：`12 + floor * 3`。
3. item.id 用 `shop_<自增序号>`（模块内局部自增 + 随机段避免跨次重复：
   `"shop_" + floor + "_" + i + "_" + rng.int(0, 99999)`）。
4. 同一 rng 序列完全可复现。

### 事件 resolveEvent

1. 选项索引越界返回 null。
2. 检查 `requireHope/requireIngots/requireHp`：任一不满足 → 返回 null，**状态零变化**。
3. 依次应用 effects：
   - hope/ingots：加到 `state.hope/ingots`（负数即消耗，但不允许扣到负数；
     若会扣成负数则该项跳过）；
   - hp：加到 `state.objectiveHp`（上限 objectiveHpCap，下限 0）；
   - relic：`"random"` 从 relicPool `rng.pick`；加入 `state.relics`；
   - ticket：加入 `recruitTickets`（value 为职业名或 "high"）；
   - operator：加入 squad 或 reserve（满编入后备）；
   - remove：从对应列表移除第一个匹配项（relic/operator），不存在则忽略。
4. 返回实际应用的效果数组（空选项返回 `[]`）。
