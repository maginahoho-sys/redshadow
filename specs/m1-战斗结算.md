# SPEC M1 —— 战斗结算系统

## 目标

实现塔防战斗的核心数值结算：伤害公式、攻击计时、目标选择、阻挡判定、死亡清理。
这是整个项目的第一个模块，行为规则全部给定，不需要自行设计。

## 交付物

- 文件：`src/systems/combat.ts`（单文件，≤ 400 行，中文注释）

```ts
import { ... } from "../contracts";   // 只用类型与 World/BattleState
```

禁止 import 其他任何模块；禁止 import Phaser；禁止修改 contracts 与 tests。

```ts
/** 伤害公式。物理：max(atk - def, atk*0.05)；法术：max(atk*(1-res/100), atk*0.05)，res 夹紧 [0,100] */
export function calcDamage(atk: number, def: number, res: number, type: DamageType): number;

/** 阻挡判定：为尚未被阻挡且已进入干员格子的敌人分配阻挡 */
export function assignBlocking(state: BattleState): void;

/** 攻击结算：处理所有干员与敌人的攻击计时、目标选择、伤害、死亡清理 */
export function combatSystem(state: BattleState, dt: number): void;
```

## 行为规则（逐条实现）

### 阻挡 assignBlocking

1. 干员占据格 = 其 `position`（整数）；敌人所在格 = `(Math.round(row), Math.round(col))`。
2. 遍历所有**未被阻挡**（`enemyPath.blockedBy === -1`）的敌人（按实体 id 升序），
   若其格子与某干员格子重合，且该干员剩余阻挡位足够，则建立阻挡：
   - 干员剩余阻挡位 = `capacity - Σ(该干员 blocked 列表中敌人的 blockWeight)`；
   - 要求 `敌人.blockWeight ≤ 剩余阻挡位`；
   - 写入：干员 `block.blocked.push(敌人id)`，敌人 `enemyPath.blockedBy = 干员id`；
   - 发事件 `{ type: "enemyBlocked", enemyId, blockerId }`。
3. 一名敌人每帧最多被一名干员阻挡；无剩余位则保持未阻挡（下帧再试）。

### 攻击 combatSystem（对每个拥有 attack 组件的存活实体）

1. **计时**：`attack.timer += dt`；`timer < interval` 则本帧不攻击。
2. **干员攻击**（faction === "operator"）：
   - 攻击范围 = `state.effective[defId].range` 相对自身格的偏移集合；
     敌人格（取整）落在偏移集合内即在范围内；
   - 目标优先级：先选**被自己阻挡**的敌人（block.blocked 中存活者），
     再选范围内其他敌人，按"路点 index 降序、到下一路点距离升序"排序；
   - `timer >= interval` 时攻击 `targetLimit` 个目标：对每个目标结算
     `calcDamage(atk, def, res, damageType)`（def/res 取目标组件值），
     目标 `health.hp -= damage`；发事件
     `{ type: "attackLanded", attacker, target, damage, damageType }`；
   - 攻击后 `timer -= interval`（允许大步长补一次攻击，不叠加多次）。
3. **敌人攻击**（faction === "enemy"）：仅当 `enemyPath.blockedBy !== -1`，
   攻击其阻挡者（无视射程），公式同上；未被阻挡的敌人不攻击。
4. **死亡清理**（结算完所有攻击后统一处理）：
   - 任意实体 `hp <= 0`：`world.destroyEntity(id)`，发
     `{ type: "entityDied", entityId, faction }`；
   - 敌人死亡：从其阻挡者的 `block.blocked` 中移除自己；
   - 干员死亡：把所有 `blockedBy === 该干员` 的敌人重置为 `-1`。
