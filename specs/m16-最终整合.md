# SPEC M16 —— 最终整合（大模型执行）

> 本模块**不交给小模型**，由大模型（积分充裕时）执行，或拆成小任务后逐项分发。

## 目标

把 M1–M15 的产物串成完整可玩的游戏：场景路由、存档、平衡、打磨。

## 任务清单

### 1. 场景串联（src/main.ts）

- BootScene：标题画面 → "新的探索" / "继续探索"（有存档时）；
- 场景路由：Boot → RogueScene（含分队选择）⇄ BattleScene，battle-finished 事件回 Rogue；
- 移除 P0 占位 BootScene 文案。

### 2. 存档（localStorage）

- 存：RunState 序列化（排除 nodeMap 中不可序列化的部分——nodeMap 本身是可序列化 POJO，直接 JSON）；
- 崮点续跑：RogueScene 从存档恢复；BattleScene 中途不存（战败/胜利结算后存）；
- 版本号字段 `saveVersion: 1`，读档时做兼容守卫。

### 3. 平衡验证清单（逐关人肉试玩）

- [ ] 教学关：初始编队 3 人能否稳定通关（不依赖运气）；
- [ ] 每层第 1 节点战斗压力 < 玩家开局资源上限；
- [ ] BOSS 关：无收藏品时险胜、2~3 件收藏品时从容；
- [ ] 负面收藏品拿到的瞬间玩家有"亏了"的感知但不算崩盘；
- [ ] 希望经济：每层大约能招募 2~3 名干员；
- [ ] 费用曲线：先锋的价值在 2、3 关后依然存在；
- 数值问题优先改 JSON（M12–M15 的包），不改系统代码。

### 4. 扩展项（可选，做完平衡后）

- 医疗干员治疗机制（M1 加 targetSelector 概念：medic 攻击目标改为治疗友军）；
- 远程敌人（EnemyDef.range + M1 敌人攻击规则扩展）；
- 干员技能（SkillDef + 触发器 hook，数据驱动）；
- 排行/统计（局末展示击杀数、部署次数）。

### 5. 发布

- `npm run build` 产物可静态托管；`workbuddy_sites_deploy` 或任意静态服务器部署；
- README.md 更新玩法说明与截图。

## 验收

完整通一局（5 层）+ 失败一局 + 刷新页面继续一局存档，全流程无控制台报错。
