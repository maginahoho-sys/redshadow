# SPEC M6 —— 肉鸽节点地图生成

## 目标

按层生成「多入口汇聚到 BOSS」的分支节点图（有向无环），类型由权重表抽样，
种子可复现。本模块纯逻辑，不涉及任何渲染。

## 交付物

- 文件：`src/meta/node-map.ts`（单文件，≤ 250 行，中文注释）

## 允许 import（白名单）

```ts
import { ... } from "../contracts";
```

## 必须导出的 API（签名一字不差）

```ts
export interface FloorConfig {
  floorName: string;
  nodeCountRange: [number, number];       // 普通节点数量区间
  weights: Partial<Record<NodeType, number>>; // 非战斗节点权重表（battle 权重缺省算 1）
}

export function generateNodeMap(floor: number, cfg: FloorConfig, rng: Rng): NodeMap;
```

## 合同速览

```ts
type NodeType = "battle" | "emergencyBattle" | "shop" | "event" | "boss"
              | "gift" | "safeCorner" | "interlude";
interface MapNode { id: string; type: NodeType; row: number; col: number; next: string[]; }
interface NodeMap { floor: number; floorName: string; nodes: Record<string, MapNode>; start: string; boss: string; }
// id 命名约定："n<floor>_<序号>"，例如 n1_0；start/boss 也在 nodes 中
// rng.pick/weighted/int/shuffle 见 contracts/rng.ts
```

## 行为规则

1. **普通节点数** = `rng.int(nodeCountRange[0], nodeCountRange[1])`。
2. **结构**（固定的 3 段式，保证分支感又实现简单）：
   - 第一段（起点）：1 个节点（start，类型 battle——第一层；或任意战斗型——通用规则见下）；
   - 中段：普通节点，分成左右两列交错（col ∈ {0,1}），前后两两相连形成分支；
   - 末段：1 个 boss 节点（type "boss"）。
   - 具体拓扑自由度：只要满足下述不变量即可，推荐"分层二叉"：
     start 连接中段前 1~2 个节点，中段节点每个连接下一排的 1~2 个节点，
     中段最后一排每个节点都连 boss。
3. **不变量（验收测试逐条检查）**：
   - 所有节点从 start 可达（沿 next 的并查集/DFS）；
   - boss 可从 start 可达；boss 的 `next` 为空；
   - 无环：任何节点沿 next 无法回到自身；
   - `next` 引用的 id 必须存在于 nodes；
   - 普通节点类型只能从 weights 的键中抽取（boss 除外）；
   - 类型抽样：把非 boss 的每个节点类型用 `rng.weighted(weights 对应权重数组)` 决定；
   - start 节点类型固定为 `"battle"`。
4. **渲染坐标**：`row` 为拓扑排数（start=0，boss=最深），`col` ∈ {0,1} 分支左右；
   boss 的 col 取 0.5（或 0，TypeScript 里 col 为 number，两者皆可）。
5. **可复现**：同一 (floor, cfg, seed) 产出完全一致的 NodeMap（JSON 级一致）。
6. weights 中 `battle` 的权重若未给，按 1 计算；全 0 权重则兜底全部为 battle。
