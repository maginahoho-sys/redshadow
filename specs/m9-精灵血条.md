# SPEC M9 —— 精灵与血条（火柴人风格）

## 目标

用 Phaser Graphics 绘制火柴人风格的干员/敌人精灵，订阅战斗事件驱动表现：
出生、移动、受击闪白、死亡淡出、阻挡连线、漏怪警示、头顶血条。

**前置**：M8 已交付（BattleScene 与 CELL 常量）。

## 交付物

- 文件：`src/render/sprites.ts`（单文件，≤ 400 行，中文注释）

## 允许 import（白名单）

```ts
import Phaser from "phaser";
import { ... } from "../contracts";
import { CELL } from "./grid-scene";
```

## 必须导出的 API

```ts
export interface SpriteLayer {
  /** 每帧同步：实体位置、血条、阻挡连线 */
  update(dt: number): void;
  destroy(): void;
}

export function createSpriteLayer(scene: Phaser.Scene, state: BattleState): SpriteLayer;
```

## 行为规则

### 火柴人绘制（纯 Graphics 线条，不用贴图）

一个实体 = 一个 `Container`（锚点在脚底中心）：

- 头：圆 r=7（描边）；躯干：竖线 18px；双臂/双腿：斜线各两条（长 12px）；
- **干员职业配色**（描边色，躯干加同色 2px 粗线突出）：
  先锋 #6fc06f | 近卫 #e2703a | 重装 #b7b7ff | 狙击 #d8b13c | 术师 #b26fe0
  | 医疗 #64d9c8 | 辅助 #6fa8e0 | 特种 #d96f9c
  （干员朝向敌人来向：双臂线朝 +col 方向）
- **敌人**：统一猩红 #d04a4a 描边，`tags` 含 "fast" 的加双头（两只圆）表示迅捷，
  `blockWeight >= 3` 的 BOSS：整体 scale 1.8 + 头顶画一顶三角"高帽"；
- 血条：实体头顶 14px 处，宽 36 高 4 的背景槽 #333 + 前景条
  （干员 #6fc06f / 敌人 #d04a4a），按 `hp/maxHp` 缩放；
- 部署格锚点换算：像素 = (40 + col*CELL, 120 + row*CELL) + (CELL/2, CELL-8)
  （40/120 是 BattleScene 的网格原点，行内注释注明来源）。

### 事件驱动（订阅 state.bus）

| 事件 | 表现 |
|---|---|
| enemySpawned | 创建敌人容器 + 0.2s 淡入 |
| operatorDeployed | 创建干员容器（颜色查 state.operatorDefs 职业）+ 落地 0.15s 放大动效 |
| operatorRetreated | 对应容器淡出移除 |
| entityDied | 容器 0.3s 旋转 90° + 淡出移除 |
| attackLanded | 目标容器 0.1s 闪白（tint 用白色矩形叠加或 alpha 脉冲） |
| enemyBlocked | 阻挡者与被阻挡者之间画 3px 虚线 #b7b7ff（存进映射，update 中保持连线） |
| enemyLeaked | 防御点位置红色脉冲圆环 |

### update（每帧）

- 对存活实体：从 `CPosition` 读连续坐标换算像素，`container.setPosition` 平滑跟随；
- 血条按 `CHealth` 更新；
- 阻挡连线两端实体任一消失则移除连线；
- 被阻挡敌人画一个小"■"角标在头顶。

### 生命周期

- `createSpriteLayer` 时对 state.world 里已存在的实体补建精灵（断线重连场景）；
- `destroy()` 取消全部 bus 订阅、销毁全部容器。

## 验收（手动）

`npm run dev` 进入战斗：敌人火柴人从蓝门走出→被近战阻挡→连线→受击闪白→
死亡淡出；干员部署有落地动效；漏怪时红门红光；BOSS 明显更大且戴帽。

`env -u NODE_OPTIONS npx tsc --noEmit` 无报错。
