# SPEC M4 —— 收藏品词条结算系统

## 目标

把收藏品/分队的声明式词条（RelicMod）结算成：干员有效属性表、敌人克隆表、
战斗全局参数、探索局初始资源。这是"千种收藏品"可扩展性的核心模块——
**词条数据完全声明式，本模块只做通用求值，不含任何具体收藏品的名字**。

## 交付物

- 文件：`src/systems/relics.ts`（单文件，≤ 300 行，中文注释）

## 允许 import（白名单）

## 必须导出的 API（签名一字不差）

```ts
/** 选择器匹配。subject: { faction, profession?, tags } */
export function matches(selector: EntitySelector, subject: {
  faction: Faction; profession?: Profession; tags: string[];
}): boolean;

/** 求值干员有效属性：base ← defs，再应用全部 stat/grantTag 词条 */
export function buildOperatorEffective(
  defs: OperatorDef[], mods: RelicMod[]
): Record<string, EffectiveStats>;

/** 求值敌人克隆表（不改动原始 defs），应用 stat/grantTag 词条 */
export function buildEnemyDefs(defs: EnemyDef[], mods: RelicMod[]): Record<string, EnemyDef>;

/** 求值战斗全局参数 */
export function buildGlobals(base: EffectiveGlobals, mods: RelicMod[]): EffectiveGlobals;

/** 求值探索局初始资源（只认 runStat 词条，其他忽略） */
export function runStartFrom(runStart: {
  hope: number; hopeCap: number; ingots: number; objectiveHp: number;
}, mods: RelicMod[]): { hope: number; hopeCap: number; ingots: number; objectiveHp: number };
```

## 合同速览

```ts
interface EntitySelector {
  faction?: Faction;              // 缺省 = 双方
  professions?: Profession[];      // 仅干员
  tagsAll?: string[];             // 必须全含
  tagsAny?: string[];             // 任一命中
}
type RelicMod =
  | { kind: "stat";      selector: EntitySelector; stat: StatKey;   op: "add"|"mul"; value: number }
  | { kind: "global";    target: GlobalKey;                         op: "add"|"mul"; value: number }
  | { kind: "grantTag";  selector: EntitySelector; tag: string }
  | { kind: "runStat";   target: RunStatKey;                        op: "add"|"mul"; value: number };
// StatKey: hp/atk/def/res/cost/attackInterval/blockCount/speed/redeployCooldown
// GlobalKey: dpRate/initialDp/objectiveHp/tempObjectiveHp/squadSize
// RunStatKey: hope/ingots/objectiveHp/hopeCap
interface EffectiveStats {
  cost: number; hp: number; atk: number; def: number; res: number;
  attackInterval: number; blockCount: number; damageType: DamageType;
  range: ReadonlyArray<readonly [number, number]>; redeployCooldown: number;
  dpBonusRate: number; tags: string[];
}
interface EffectiveGlobals { dpRate; initialDp; objectiveHp; tempObjectiveHp; squadSize; }
// 干员的匹配 subject: { faction: "operator", profession: def.profession, tags: def.tags ?? [] }
// 敌人的匹配 subject: { faction: "enemy", tags: def.tags ?? [] }
```

## 行为规则

1. **求值顺序**：同一实体的同一属性，先汇总全部 `add`，再汇总全部 `mul`
   （mul 连乘）。例如 atk 320 + [add 100, mul 1.2] → (320+100)*1.2 = 504。
2. **匹配**：`matches` 按 faction / professions / tagsAll / tagsAny 组合过滤，
   条件之间是交集；未给出的条件不做限制。
3. `buildOperatorEffective`：基准值来自 OperatorDef（dpBonusRate 缺省 0），
   grantTag 词条把 tag 追加进 `tags`（保持基准 tags 顺序，新 tag 去重）。
4. `buildEnemyDefs`：返回**克隆**（浅拷贝 + 修改后的属性），原始 defs 不许被改动；
   可命中的 StatKey 仅 hp/atk/def/res/speed；grantTag 合并进 tags。
5. `buildGlobals`：只认 `kind === "global"`；同样先 add 后 mul；base 为基准。
6. `runStartFrom`：只认 `kind === "runStat"`；hope/hopeCap/ingots/objectiveHp 四项。
7. 词条列表中与本函数无关的 kind 一律忽略（不抛错）。
