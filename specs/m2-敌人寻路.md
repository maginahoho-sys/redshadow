# SPEC M2 —— 敌人寻路移动系统

## 目标

让敌人沿路点序列移动，被阻挡时停住，抵达终点（防御点）时漏怪扣目标生命。

## 交付物

- 文件：`src/systems/movement.ts`（单文件，≤ 200 行，中文注释）

## 允许 import（白名单）

```ts
import { ... } from "../contracts";
```

## 必须导出的 API（签名一字不差）

```ts
/** 每帧推进所有敌人的移动；处理终点漏怪 */
export function movementSystem(state: BattleState, dt: number): void;
```

## 合同速览

```ts
interface CPosition { row: number; col: number; }  // 连续坐标（浮点）
interface CEnemyPath {
  waypoints: Vec2[];  // 路点序列，index 是"下一个要到达的路点"下标（从 1 开始）
  index: number;
  speed: number;       // 格/秒
  blockedBy: number;   // !== -1 表示被阻挡
  blockWeight: number; leakDamage: number;
}
// state.objectiveHp: 目标生命；state.bus: 事件总线
// 事件: { type: "enemyLeaked", entityId, leakDamage }
```

## 行为规则

1. 遍历 `world.query("enemyPath")`（升序）。
2. `blockedBy !== -1` 的敌人本帧不动。
3. 本帧可移动预算 = `speed * dt`，**逐路点消耗**（大步长不允许跳过路点）：
   - 对当前目标路点 `waypoints[index]`：**先对齐 row，再对齐 col**
     （先纵向移动到同 row，再横向移动到同 col）；
   - 向目标坐标靠近直到预算用完或抵达该路点；抵达则 `index += 1`，继续下一个路点。
4. 到达最后一个路点（`index === waypoints.length` 的判定时机：越过或恰好等于
   末点坐标）→ 漏怪：
   - `state.objectiveHp -= leakDamage`；
   - 发事件 `{ type: "enemyLeaked", entityId, leakDamage }`；
   - `world.destroyEntity(entityId)`。
5. 浮点误差：位置判定允许 1e-6 容差；"恰好停在终点格但未越过"不算漏怪。
