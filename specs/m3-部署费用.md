# SPEC M3 —— 部署与费用系统

## 目标

实现干员部署/撤退的合法性判定、费用自然回复、先锋费用加成、再部署冷却。

## 交付物

- 文件：`src/systems/deployment.ts`（单文件，≤ 350 行，中文注释）

## 允许 import（白名单）

```ts
import { ... } from "../contracts";
```

## 必须导出的 API（签名一字不差）

```ts
export interface DeployCheck { ok: boolean; reason?: string; }

/** 判定某干员能否部署到某格（不产生任何变化） */
export function canDeploy(state: BattleState, operatorId: string, cell: Vec2): DeployCheck;

/** 部署成功返回实体 id，失败返回 -1 且状态零变化 */
export function deployOperator(state: BattleState, operatorId: string, cell: Vec2): number;

/** 撤退：全额退费、进入冷却、移除实体、解除其阻挡的敌人；成功返回 true */
export function retreatOperator(state: BattleState, operatorId: string): boolean;

/** 帧更新：费用回复（含先锋加成）、冷却倒计时 */
export function deploymentSystem(state: BattleState, dt: number): void;
```

```ts
// state.squad: { operatorId, state: "ready"|"deployed"|"cooldown", cooldownRemaining, entityId? }[]

// 事件: operatorDeployed / operatorRetreated
```

## 行为规则

### canDeploy（按序判定，任一失败即返回并给出 reason）

1. operatorId 必须在 `state.squad` 中且成员状态为 `ready`；
2. 格子在地图范围内；
3. 地形合法：melee 只能部署 `'r'`；ranged 只能部署 `'h'`；`S/G/#/.` 一律不可部署；
4. 格子上没有其他干员（查 `world.query("block")` 的 position）；
5. `state.dp >= effective[operatorId].cost`。

### deployOperator

1. 先 `canDeploy`，不通过返回 -1；
2. 扣除 `dp`；
3. 创建实体并挂组件（identity/position/health/attack/block/tags），
   数值全部取自 `state.effective[operatorId]`：
   - health: `{ hp, maxHp }`；attack: `{ atk, def, res, damageType, interval, timer: 0, targetLimit: 1 }`；
   - block: `{ capacity: blockCount, blocked: [] }`；tags: `{ tags: [...] }`；
4. 更新 SquadMember：`state = "deployed"`，记录 `entityId`；
5. 发事件 `{ type: "operatorDeployed", entityId, operatorId, at: cell }`。

### retreatOperator

1. 成员必须处于 `deployed`，否则 false；
2. 销毁实体；把 `blockedBy === 该实体` 的全部敌人重置为 -1；
3. 全额退费 `dp += cost`（cost 取 `state.effective` 当前值）；
4. 成员 → `cooldown`，`cooldownRemaining = redeployCooldown`；
5. 发事件 `{ type: "operatorRetreated", operatorId }`。

### deploymentSystem（每帧）

1. 费用回复：`dp += (globals.dpRate + Σ已部署先锋的 dpBonusRate) * dt`；
2. 冷却：对所有 `cooldown` 成员 `cooldownRemaining -= dt`，`<= 0` 时归零并置 `ready`。
